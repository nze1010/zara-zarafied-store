# ZARA — ZARAFIED STORE: Initial Brand Assets

This folder contains local working copies for Layer 1 development.

## Files
- `brand/zara-logo.png` — refined logo version without the decorative flower beside the final A.
- `owner/owner-portrait-red-dress.png` — owner portrait reference for the homepage hero and welcome card.
- `owner/owner-outfit-reference-collage.png` — additional owner/outfit reference; do not use the collage as the primary hero unless approved.
- `fashion/signature-fashion-01-ankara.png` — supplied signature fashion photo.
- `fashion/signature-fashion-02-paired-looks.png` — supplied fashion photo with two outfits.
- `fashion/signature-fashion-03-colourful-dress.png` — supplied colourful fashion photo.

## Use rules
1. Preserve originals. Do not crop, retouch, recolour, or alter the owner's appearance without approval.
2. Use the actual supplied assets, not generated substitutes.
3. Use the portrait for the owner-led hero and welcome card; use fashion photos for the slideshow/preview.
4. These are local development assets. Product and portfolio media should later be uploaded through the admin dashboard to Firebase Storage, with metadata/paths in Cloud Firestore.
5. Do not put secrets or private customer information in this folder.
